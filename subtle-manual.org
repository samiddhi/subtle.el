\<subtle-mode-map>

subtle plays an audio or video file in mpv and shows each subtitle file
(=.srt= or =.vtt=, up to two at once) as read-only text in Emacs.  The cue
being spoken is highlighted and the text follows the audio.  It is made for
studying a language: the text stays still until the page needs turning,
scrolling by hand pauses the autoscroll, and paragraph layouts turn cue
fragments into running text.

If you are new, start with the tutorial (=M-x subtle-tutorial=).  This
manual is the full description.  Everything here that mentions a key shows
the key you have bound when read with =M-x subtle-manual=, and the default
key in the Info version.

* Overview

** Requirements

Emacs 29.1 or later, and mpv on your =PATH= (or set
=subtle-mpv-executable=).  subtle talks to mpv through its JSON IPC
socket, so Windows is not supported.

** Starting and stopping

- =M-x subtle-open= asks for a media file and one or two subtitle files.
- =M-x subtle-dired-open= does the same from Dired: it uses the marked
  files, or the file at point, and finds missing subtitles by file name
  (=film.mkv=, =film.sl.srt=).
- =\[subtle-quit]= closes what is open on screen (a popup, the help box),
  and with nothing open asks whether to quit.  =M-x subtle-close= ends the
  session without asking.
- =M-x bookmark-set= in a subtle buffer records the media, subtitles and
  time.  Jumping to the bookmark (=subtle-bookmark-jump=) reopens them
  =subtle-bookmark-rewind= seconds earlier, paused unless
  =subtle-bookmark-autoplay= is set.

** Autoscroll

Autoscroll moves the window only when the spoken cue is off screen or has
entered a page margin.  Pausing, resizing the window, or the automatic
resume never move the text by themselves.  Scrolling by hand stops the
autoscroll and shows a notice; it resumes after =subtle-resume-delay=
seconds (if =subtle-auto-resume= is on) or when you press
=\[subtle-resume-follow]=.

** Layouts

=subtle-layout= decides how cues are arranged.

| Layout            | Meaning                                            |
|-------------------+----------------------------------------------------|
| =single-spaced=   | one cue per line (default)                         |
| =double-spaced=   | a blank line between cues                          |
| =sentence=        | a line break after each sentence                   |
| =paragraph-flow=  | running text, broken at paragraph breaks           |
| =paragraph-pause= | like flow; playback pauses at each break          |

Paragraph breaks come from blank lines or empty cues in the file and, when
=subtle-paragraph-source= is =explicit-and-gap=, from silences of
=subtle-paragraph-gap= seconds after a sentence end.

* Options

Set an option with =setopt= (or Customize) and a running session changes at
once for the options that can: layout, text size, fill columns and the
notice style.  The rest are read when they are used.  =\[subtle-set-option]=
(=subtle-set-option=) asks for an option and a value and sets it for the
rest of the Emacs session; it is a thin wrapper over
=customize-set-variable=.

The strip is an alist of (COMMAND . LABEL).  The key shown is looked up in
=subtle-mode-map=, so rebinding a key changes the strip too:

#+begin_src emacs-lisp
(setopt subtle-control-strip
        '((subtle-toggle-pause . "pause")
          (subtle-previous-cue . "prev")
          (subtle-next-cue . "next")
          (subtle-help . "help")))
#+end_src

** Point tracking

Point tracking makes point follow the playback: at every new cue it jumps to
the word a package chose (bltzread: the first unknown one), or to the start
of the cue when none was chosen.  \\[subtle-point-track-toggle] switches it on and
off.  Moving point off the cue pauses it (the state is "released") until point is back on the cue, or the cue reaches the line point is on; then it tracks again without moving point.  A tracking you switched off stays off.
Moving point less than =subtle-point-track-nav-grace= seconds before a cue change
releases it as well, so a word you are just reading is not snatched away.
A card that is open when point moves is dismissed, and
=subtle-point-track-moved-functions= then lets a package show something for the
new word: bltzread opens its card there, so no key is needed.

| Option                         | Default | Meaning                                    |
|--------------------------------+---------+--------------------------------------------|
| =subtle-point-track-initially=          | t       | Point jumps to the chosen word of each new cue. |
| =subtle-point-track-nav-grace=       | 0.25    | Moving point this many seconds before a cue change releases tracking. |
| =subtle-point-track-indicator=       | t       | Show a small corner box while point tracking is on. |

* Commands

Besides the keys above:

- =subtle-open= (media and subtitle files) and =subtle-dired-open=.
- =subtle-close= ends the session at once.
- =subtle-bookmark-jump= is the bookmark handler.
- =subtle-manual= and =subtle-tutorial= show these documents.
- =subtle-set-option= takes an OPTION and a VALUE, reading them from the
  minibuffer when called interactively.  Complex values are read as Lisp
  and checked against the option's type.
- =subtle-set-layout= takes a LAYOUT.

* Hooks

Every hook is also a customizable option, so use =add-hook= or Customize.

** Normal hooks

| Hook                         | Runs                                           |
|------------------------------+------------------------------------------------|
| =subtle-open-hook=           | once a session is open (buffers shown, mpv started); =subtle-current-session= is the new session. |
| =subtle-buffer-setup-hook=   | in each subtitle buffer, once built; =subtle-track-index= and =subtle-language= are set. |
| =subtle-pause-hook=          | in a subtitle buffer when you pause. Not for pauses subtle makes itself. |
| =subtle-rebuild-hook=        | after the text was redrawn for a changed option. |
| =subtle-before-close-hook=   | when a session closes, buffers still alive. The place to ask questions. |
| =subtle-close-hook=          | just before the buffers are killed.            |

** Abnormal hooks

| Hook                               | Arguments, and what is done with the result |
|------------------------------------+---------------------------------------------|
| =subtle-cue-change-functions=      | BUFFER INDEX: a new cue became the spoken one in BUFFER (INDEX is nil in a gap). |
| =subtle-before-cue-change-functions= | BUFFER INDEX: just before the above, before the window scrolls. |
| =subtle-follow-change-functions=   | SESSION FOLLOW: autoscroll stopped or resumed. |
| =subtle-mpv-message-functions=     | SESSION MESSAGE: a message from mpv, after subtle handled it.  MESSAGE is (time-pos . SECONDS), (pause . BOOL) or (speed . NUMBER); keep the functions quick. |
| =subtle-hold-functions=            | none: autoscroll waits while one returns non-nil. |
| =subtle-anchor-functions=          | none: return a position to keep on screen, or nil. |
| =subtle-dismiss-functions=         | none: close something on screen; the first non-nil wins. |
| =subtle-cue-point-functions=       | BEG END of the cue: return where point should go, or nil. The first answer wins. |
| =subtle-point-track-moved-functions=     | BUFFER POS: point tracking just moved point to POS; show something about the word there. |

The variables =subtle-track-index= and =subtle-language= are set in every
subtitle buffer.

** Adding a key

#+begin_src emacs-lisp
(keymap-set subtle-mode-map "SPC" #'subtle-toggle-pause)
#+end_src

The help box and the control strip read the keymap, so the new key appears
in both.

** React to the spoken cue

#+begin_src emacs-lisp
(add-hook 'subtle-cue-change-functions
          (lambda (buffer index)
            (when index
              (message "%s: cue %d" (buffer-name buffer) index))))
#+end_src

** Recipe: studying at a slow speed

#+begin_src emacs-lisp
(setopt subtle-scroll-style 'paged
        subtle-move-point 'never
        subtle-speed-step 0.05)
#+end_src

Press =\[subtle-slower]= until the speed is about 0.8.  With paged
scrolling the text does not move under you when you pause to look at a word.

** Using subtle with bltzread

bltzread is a separate package that marks and looks up words.  subtle does
not need it.  To annotate the track you study and to give reading credit
only for what was played:

#+begin_src emacs-lisp
(with-eval-after-load 'bltzread
  (setq bltzread-range-farthest-source #'subtle-played-through-position
        bltzread-range-start-function  #'subtle-played-start-position))

(add-hook 'subtle-buffer-setup-hook
          (lambda ()
            (when (and (= subtle-track-index 0) (require 'bltzread nil t))
              (setq-local bltzread-language subtle-language)
              (bltzread-mode 1))))
#+end_src

bltzread subscribes to subtle's hold, anchor, dismiss and cue point
functions itself when it is loaded.  Its other functions can be added to
=subtle-pause-hook= like any other:

#+begin_src emacs-lisp
(add-hook 'subtle-pause-hook
          (lambda () (when bltzread-mode (bltzread-avy-unknown))))
#+end_src
